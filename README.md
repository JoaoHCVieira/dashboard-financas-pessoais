# 💰 Dashboard de Finanças Pessoais

Aplicação web interativa desenvolvida para o controlo financeiro pessoal, permitindo o registo de entradas e saídas, o cálculo automático do saldo e a visualização dinâmica de gráficos por categoria.

## 🚀 Tecnologias Utilizadas
- **HTML5**: Estrutura semântica da página.
- **CSS3**: Estilização moderna e responsiva.
- **JavaScript (Vanilla)**: Lógica da aplicação, manipulação do DOM e persistência de dados.
- **Chart.js**: Biblioteca externa para a renderização do gráfico de rosca de despesas.
- **LocalStorage**: Armazenamento local para manter os dados salvos diretamente no navegador.

## ✨ Funcionalidades
- Registo de transações (Descrição, Valor, Tipo: Entrada/Saída e Categoria).
- Cartões de resumo atualizados em tempo real (Total de Entradas, Saídas e Saldo).
- Histórico dinâmico de transações com opção de exclusão.
- Gráfico de rosca dinâmico com a distribuição dos gastos por categoria.
- Validação de formulários para garantir a consistência dos dados inseridos.
